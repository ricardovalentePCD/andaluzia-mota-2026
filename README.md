# 🏍️ Andaluzia de Mota — Outubro 2025

Roteiro de mota de 5 dias pelo Sul de Espanha.
**Queijas → Sevilha → Ronda → Granada → Sevilha → Queijas** (~1450 km)

## Site
Ver roteiro completo: https://ricardovalentePCD.github.io/andaluzia-mota-2025

## Dias
- Dia 1: Queijas → Sierra Morena → Sevilha (~330 km)
- - Dia 2: Sevilha → El Chorro → Pueblos Blancos → Ronda (~260 km)
  - - Dia 3: Ronda → A-397 → Costa del Sol → Alpujarras → Granada (~290 km)
    - - Dia 4: Granada → Ruta del Califato → Grazalema → Sevilha (~340 km)
      - - Dia 5: Sevilha → Algarve → N2 → Queijas (~360 km)
